# Naloga: Web Faza 2 — produkcijska intranet nadgradnja MES Excel Validatorja

**Datum:** julij 2026  
**Jezik vmesnika:** slovenščina  
**Ciljno okolje:** samo službeno notranje omrežje (intranet), brez javnega interneta  
**Trajanje:** večurno / večdnevno delo — implementiraj celotno fazo 2 do konca, ne MVP skeleta

---

## 0. Kontekst (OBVEZNO PREBERI PRED KODO)

Obstaja delujoč Python projekt **validator_oop** — validacijski engine za farmacevtske MES/IPO recepture.

**Web MVP je že implementiran** v mapi `web/`:
- FastAPI backend: `web/backend/` (`app.py`, `jobs.py`, `service.py`, `schemas.py`, `settings.py`, `rules_catalog.py`)
- React frontend (vendoran, brez npm build): `web/frontend/`
- Docker on-prem: `web/deploy/`
- Zaganjalnik: `run_web.py`
- Testi: `tests/test_web_api.py`
- Dokumentacija MVP: `docs/PROMPT_WEB_APLIKACIJA.md`, `web/README.md`

### Kaj MVP že zna (NE PREPISUJ)
- Upload receptur (.xlsx/.xlsm) + SOP + šifranti
- Validacija tipov datotek (HTTP 415)
- Background jobi (ThreadPoolExecutor) + polling napredka
- Rezultati: filtri, grupiranje, graf, Sartorius tema
- Prenosi: Excel/JSON/TXT/autofix + skupno batch poročilo
- Offline frontend (vendorani React/Babel)

### Kaj Faza 2 mora dodati
1. **AD / LDAP avtentikacija** + role (tehnolog / QA / admin)
2. **Audit trail** (kdo, kdaj, kaj)
3. **Zgodovina validacij** (trajna, ne samo temp job TTL)
4. **Primerjava razdelkov med listi** (funkcija iz desktop GUI, trenutno TODO)
5. **WebSocket** real-time progress (namesto/ob pollingu)
6. **HTTPS / AD CS** priprava v nginx + dokumentacija
7. **Diff dveh verzij recepture** (dve datoteki / dva joba)

### Stroga pravila
1. **NE piši validacijske logike na novo.** Engine ostane v `core/`, `rules/`, `excel/`.
2. **NE refaktoriraj** `control.py`, `shared_context.py`, relational/field pravil — razen če primerjava razdelkov zahteva **nov izoliran modul** v `excel/` ali `web/`.
3. Desktop GUI (Tkinter/Qt) in CLI morata še naprej delovati.
4. Aplikacija mora delovati **brez interneta** (brez CDN, brez SaaS, brez cloud auth).
5. Frontend ostane **vendoran** (brez npm produkcijskega builda), razen če eksplicitno dodaš lokalni vendor paket — ne uvajaj Vite/npm kot obveznost.
6. Vsaka sprememba kode → posodobi `CHANGELOG.md` pod `[Unreleased]` (slovensko, z datumom in oceno časa; samo DODAJ vnose, ne briši starih).
7. Vsi UI nizi so v **slovenščini**. Tema: Sartorius (#000000 / #FFE600 / #f5f5f5).

## 1. Cilj Faze 2

Zgraditi produkcijsko intranet plast, kjer tehnolog/QA:
1. se prijavi z AD/LDAP (ali lokalnim fallback uporabnikom v dev načinu),
2. validira recepture kot doslej,
3. vidi **zgodovino** preteklih validacij,
4. ima **audit** sledljivost za GxP/QA,
5. lahko **primerja razdelke** med listi iste recepture,
6. lahko **primerja dve verziji** recepture (A vs B),
7. vidi napredek v **realnem času** prek WebSocketa,
8. vse to teče on-prem v Dockerju z možnostjo HTTPS.
